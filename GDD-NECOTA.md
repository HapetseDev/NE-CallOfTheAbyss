
## 2.3 Sekundäre Gameplay Loops

Welche kleineren Kreisläufe existieren?

### Kampf

```text
Begegnen
→ Einschätzen
→ Handeln
→ Kämpfen
→ Belohnung
```

### Erkundung

```text
Gebiet betreten
→ Orte entdecken
→ Geheimnisse finden
→ Ressourcen sammeln
→ neue Möglichkeiten erhalten
```

### Charakterentwicklung

```text
Erfahrung
→ neue Fähigkeiten
→ neue Möglichkeiten
→ neue Herausforderungen
```
